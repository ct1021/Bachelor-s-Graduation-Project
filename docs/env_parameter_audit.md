# 环境参数审计报告：对标任务书性能指标

> **目的**：确保 `g1_env.py` 的物理参数与训练配置，能够满足任务书所列的考核性能指标，避免训练完成后才发现指标无法达标。

---

## 一、任务书核心性能指标（官方要求）

从任务书提取的量化考核指标：

| 指标 | 任务书原文要求 | 
|---|---|
| **控制频率** | 力板/IMU ≥ 100Hz（控制环），IMU ≥ 200 Hz |
| **速度跟踪** | 实现速度阶跃、持续行走和轻度扰动仿真实验 |
| **仿真实验** | cm台阶通过能力（不指定高度但需报告）|
| **轨迹/速度跟踪误差** | 质心高度波动与速度跟踪误差**优于纯IL基线** |
| **跌倒率** | 需汇报（越低越好，目标接近 0%）|
| **足端滑移率** | 需汇报（越低越好）|
| **能耗 COT** | 需汇报单位距离能耗 |
| **步态对称性指数** | 需汇报 |
| **Sim2Real** | 策略在仿真环境中完成部署和测试 |

## 三、最关键修复：提升控制频率到 100Hz

```python
# g1_env.py 第26行 — 修改
self.dt = 0.01   # 控制频率 100Hz (任务书要求 ≥100Hz)
# frame_skip 会自动变为 int(0.01 / 0.002) = 5 帧
```

> [!IMPORTANT]
> 提高频率会让每个 episode 消耗的真实时间和 GPU 算力大约翻倍。如果服务器资源允许，建议在下次训练前合并此修改。
